VibePaint

A layered painting app in the browser, designed so the tools step back and the artwork comes forward.

Open VibePaint
Role
Interface design, AI-directed build
Status
Working prototype
Built with
HTML, Canvas, Tailwind, Gemini
Best on
Desktop, mouse or pen

The goal

Most browser paint tools bury the canvas under toolbars. I wanted the opposite: a calm, dark workspace where the painting is the brightest thing on screen and every control is one reach away.

Key design decisions

1. The canvas gets the room

Tools live in a narrow rail on the left, and layers float in a panel on the right. Everything else is canvas. The panel is translucent, so you never lose track of the painting underneath it.

2. A palette that recedes

The interface is near-black with a single olive accent for the active tool and layer. The swatches run from light to dark and then through a set of earthy greens, so the defaults already sit well together.

3. Shortcuts where artists expect them

Brush (B), Eraser (E), Line (L), Rectangle (R), Circle (C), plus Undo and Redo with Ctrl+Z and Ctrl+Y. Every shortcut is shown in the tool's tooltip, so you learn them just by hovering.

4. Layers and adjustments, kept simple

Layers can be added, hidden and faded with an opacity slider. The Adjust tab offers brightness, contrast, grayscale and blur, and "Bake filters to layer" commits them when you're happy. Undo keeps the last 20 steps. When you're done, Export PNG saves the result.

Working with AI

VibePaint was built with Gemini from my design direction: the layout, palette and tool set came first, then rounds of review on spacing, states and shortcuts.

What's next

  • Pressure-sensitive brushes for pen tablets.
  • Drag-to-reorder layers and blend modes.
  • A touch-friendly layout for tablets.
